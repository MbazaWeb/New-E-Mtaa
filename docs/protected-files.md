# Protected Files

These files/paths must NOT be altered without explicit approval (visual source-of-truth):

- `tailwind.config.js` (root)
- Landing page file (e.g. `apps/web/app/(public)/page.tsx`, `index.html`, or equivalent)
- `src/styles/globals.css`
- `public/manifest.json`
- Brand assets: `src/assets/logo*`, `public/favicon*`

If you're unsure whether a file is protected, list it here and request review before changing.
